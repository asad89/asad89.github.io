# Muhammad Asad Iqbal — Portfolio

A responsive one-page starter portfolio for a UI/UX designer.

The current version includes an art-directed upper-body portrait, scroll-based parallax,
animated orbit details, kinetic type, a sticky process narrative, and
reduced-motion accessibility support. It also features a responsive expertise
bento grid, scroll-reactive design principles, and an animated interaction lab.

## Updating the portfolio

- Replace the two placeholder project cards in `index.html` with real case studies.
- Add an email or social link in the contact section when ready.
- Change colors and layout variables at the top of `styles.css`.

The site is intentionally dependency-free and can be hosted directly on GitHub Pages.
